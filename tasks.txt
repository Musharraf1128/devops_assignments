  ## S5 Git

  Use a temporary Git repository so this task does not affect the homework repository:

  cd /tmp
  mkdir git-practice
  cd git-practice
  git init -b main
  git config user.name "Musharraf"
  git config user.email "your-email@example.com"

  echo "first line" > commit-a.txt
  git add commit-a.txt
  git commit -m "add commit a file"

  echo "second line" >> commit-a.txt
  git commit -a -m "update tracked file using -a"
  git log --oneline

  Screenshot → images/s5-commit-a.png

  echo "main commit 1" > main.txt
  git add main.txt
  git commit -m "add main commit 1"

  git switch -c feature-cherry-pick
  echo "feature commit 1" > feature.txt
  git add feature.txt
  git commit -m "add feature commit 1"
  echo "feature commit 2" >> feature.txt
  git commit -am "add feature commit 2"
  git log --oneline

  Screenshot → images/s5-feature-log.png

  Copy the commit hash for add feature commit 1, then:

  git switch main
  git cherry-pick <paste-feature-commit-hash-here>
  git log --oneline
  cat feature.txt

  Screenshot → images/s5-cherry-pick.png
